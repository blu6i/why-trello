why-trello

Простой стек для практики Docker Compose: Nginx как веб-сервер и реверс-прокси к PHP-FPM 8.5 (чистый PHP, без фреймворков), PostgreSQL 18 как база данных. Все три образа собираются локально из Dockerfile.

Компоненты стека

Проект построен на изолированных сервисах, управляемых через Docker Compose:

  • Nginx: реверс-прокси, отдача статики и перенаправление запросов на FastCGI.
  • PHP-FPM 8.5: окружение исполнения с поддержкой расширений для работы с PostgreSQL (pdo_pgsql).
  • PostgreSQL 18: реляционная СУБД с настроенной схемой и миграциями данных.
